# Civil-Engineering-Projects

## 1. Design and Analysis of Cable-Stayed Bridges (STAAD.Pro)

### Overview
3D structural analysis of a cable-stayed bridge subjected to static, vehicle, wind, and seismic loadings using STAAD.Pro.

### Key Highlights
- **Materials Evaluated:** Steel, CFRP, BFRP, AFRP, and GFRP.
- **Key Analyses:** Displacements, axial forces, bending moments, plate stresses, and support reactions under dynamic combinations.
- **Tools Used:** STAAD.Pro, MS Excel.

## 2. Design and Analysis of Deep Beams (ABAQUS)

### Overview
Structural behavior evaluation of reinforced concrete (RC) deep beams with varying span-to-depth ($L/D$) ratios subjected to static, modal, and seismic time-history loadings using ABAQUS and ACI 318-19 design principles.

### Key Highlights
- **Analysis Approach:** Finite element analysis utilizing Concrete Damaged Plasticity (CDP) alongside Strut-and-Tie Modeling (STM) per ACI 318-19.
- **Key Parameters:** Analyzed von Mises stress contours, vertical displacements ($U2$), natural frequencies, base shear, peak acceleration, and damage degradation (`DAMAGET`).
- **Tools Used:** ABAQUS, MS Excel, AutoCAD.
